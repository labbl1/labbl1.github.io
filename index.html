EXPERIMENT 02

산화·환원 가상 실험

시약을 조금씩 넣고, 용액 속 양이온과 금속의 변화를 직접 관찰해 봐요.

실험 A · 아연 + 황산구리

반응 O

Zn + Cu²⁺ → Zn²⁺ + Cu

아연이 전자를 잃어 Zn²⁺가 되고, Cu²⁺는 전자를 얻어 구리 금속으로 석출돼요.

황산구리 용액: 0 mL

용액 속 Cu²⁺: 0

용액 속 Zn²⁺: 0

전체 양이온 수(모형): 0

먼저 황산구리 용액을 넣어 보세요.

실험 B · 알루미늄 + 황산구리

반응 O

2Al + 3Cu²⁺ → 2Al³⁺ + 3Cu

반응이 진행되면 Cu²⁺ 3개가 줄고 Al³⁺ 2개가 생기는 비율로 단순화해요. 따라서 용액 속 양이온 수가 줄어들 수 있어요.

황산구리 용액: 0 mL

용액 속 Cu²⁺: 0

용액 속 Al³⁺: 0

전체 양이온 수(모형): 0

먼저 황산구리 용액을 넣어 보세요.

모형 읽기

입자 한 개는 일정량의 이온을 대표해요. 이 모형은 반응 비율을 보여 주며 실제 용액의 농도·반응 속도·금속 표면 상태를 완전히 재현하지는 않아요. Zn + Cu²⁺ 반응은 양이온 종류가 바뀌지만 1:1이라 전체 수가 같고, Al + Cu²⁺ 반응은 반응식의 비율상 양이온 수가 감소해요. 이 두 반응만으로 양이온 수가 증가하는 사례를 억지로 만들면 실제 수용액 화학과 맞지 않을 수 있어요.
